Connect a client

Use the hosted endpoint, or run it on your own machine with npx -y ireland-mcp (Node 22.12+).

claude_desktop_config.json — or add the hosted URL under Settings → Connectors.

{
  "mcpServers": {
    "ireland": { "command": "npx", "args": ["-y", "ireland-mcp"] }
  }
}

.vscode/mcp.json

{
  "servers": {
    "ireland": { "type": "http", "url": "https://YOUR-APP.azurewebsites.net/mcp" }
  }
}

.mcp.json or ~/.copilot/mcp-config.json

{
  "mcpServers": {
    "ireland": { "type": "http", "url": "https://YOUR-APP.azurewebsites.net/mcp", "tools": ["*"] }
  }
}

Settings → Apps & Connectors → Advanced → Developer mode, then create a connector with:

https://YOUR-APP.azurewebsites.net/mcp
Authentication: none

Deep research uses the search and fetch tools. Availability of developer mode varies by plan and region.

Try it

Calls the live server from your browser. Requests are rate limited to about 60 a minute per address.


      

    


    

      
Built to be trusted

      
    
        
  • Read-only. Every tool is annotated readOnlyHint; nothing writes anywhere.
    • 
        
  • Evidence on every answer. Source, licence, upstream URL and retrieval time travel with the data.
    • 
        
  • Honest failures. Typed errors — UPSTREAM_DOWN, NOT_FOUND, BAD_ARGS, RATE_LIMITED — and clearly marked stale cache when a source is down.
    • 
        
  • No accounts, no tracking. No sign-in and no personal data stored.
